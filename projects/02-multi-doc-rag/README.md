# 项目 2：多文档知识库问答

**建议学习周**：第 9 周 | **目标**：多文件 + 标签/部门过滤

## 做什么

1. 支持多个 PDF/TXT，统一切块并打上「来源、部门、类型」等元数据。
2. 向量化时把元数据存进向量库，检索时可按「只在某类文档里查」过滤。
3. 提供简单入口：指定目录或文件列表 → 建索引 → 提问时可选范围。

## 通俗理解

- **多文档**：像公司有「人事制度」「财务制度」「项目文档」，都放进一个知识库，但检索时可以说「只在人事制度里找」。
- **元数据**：每段文字带上标签（如 `部门=人事`），查的时候先筛标签再算相似度，结果更准。

## 步骤建议

1. 用 LangChain 的 `DirectoryLoader` 或自己遍历目录，加载多种格式。
2. 切块时保留「文件名/部门」到 `metadata`，写入 Chroma 时用 `metadatas`。
3. 检索时 `collection.query(..., where={"department": "人事"})`（具体看 Chroma 文档）。

## 文件说明

- `multi_rag.py`：多文档加载、带 metadata 的索引与查询。
- `data/`：子目录如 `hr/`、`finance/`，各放若干 PDF/TXT。

## 运行示例

```bash
python multi_rag.py --data-dir data --query "年假怎么算" --filter-department hr
```

## 扩展（可选）

- 前端下拉选择「部门/类型」再提问。
