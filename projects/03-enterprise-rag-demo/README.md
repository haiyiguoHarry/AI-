# 项目 3：企业场景 RAG Demo

**建议学习周**：第 12 周 | **目标**：选一个真实场景，做可演示的完整 Demo

## 做什么

选一个贴近你工作的场景，从数据到界面全走通：

- **场景 A**：公司制度问答（如考勤、报销、年假）
- **场景 B**：项目 Wiki / 技术文档问答
- **场景 C**：客服 FAQ（把历史问答整理成文档，再 RAG）

步骤：准备/清洗文档 → 切块与检索调优 → 设计提示词（角色+格式）→ 用 FastAPI 或 Streamlit 做简单 Web → 自测 10 个问答对并记录效果。

## 通俗理解

- **数据清洗**：去掉页眉页脚、乱码、无关段落，让检索到的「块」更干净。
- **提示词**：例如「你是公司 HR 助手，只根据以下制度用 3 条以内回答，不要编造」。
- **效果自测**：像训练师一样，列 10 个「问题+标准答案」，跑一遍看答对几条，再调切块/提示词。

## 步骤建议

1. 用 3～5 份真实或脱敏文档，放到 `data/`。
2. 用项目 1/2 的流程建索引，并写好「企业风」的 system prompt。
3. FastAPI：`POST /query` 接收 `{"question": "..."}`，返回 `{"answer": "...", "sources": [...]}`。
4. 用 Streamlit 或简单 HTML 做一个问答页面，可录屏展示。

## 文件说明

- `app.py`：FastAPI 或 Streamlit 入口。
- `rag_engine.py`：封装建索引、检索、调 LLM。
- `data/`：制度或 FAQ 文档。
- `eval_qa.json`：自测问答对，格式 `[{"q": "...", "a": "..."}]`。

## 运行示例

```bash
# 先建索引（或启动时自动建）
python rag_engine.py --build-index --data-dir data
# 再启动 Web
streamlit run app.py
# 或
uvicorn app:app --reload
```
